项目介绍
关于 Aurora
Aurora 是一款自研、轻量化、面向现代化开发的PHP 模块化底层组件库。项目专注于底层通用能力封装与特殊二进制协议通信场景，采用高内聚、低耦合的分层架构设计，模块完全解耦、可独立引用、扩展性极强。
本库不绑定任何 PHP 框架，可无缝接入 ThinkPHP、Laravel、Symfony 等所有主流 PHP 项目，适用于新旧项目的底层能力升级与协议通信改造。
✅ 运行环境强制要求：PHP 8.0 +
项目全程使用 PHP8 新特性（命名参数、类型严格约束、match、高级类型声明等），不支持 PHP7 及以下版本。
整体架构与能力划分
Aurora 整体架构清晰分层，分为 通用基础模块 与 特色协议通信模块 两大体系，各司其职、互不耦合：
基础公共模块
封装项目通用底层能力，为所有上层业务提供稳定支撑：
- 二进制流读写组件：统一封装内存流、输入流，原生处理 PHP 原始二进制数据，无编码污染、无框架干扰
- 全局统一异常体系：标准化业务异常、协议异常、解析异常抛出规范，便于全局捕获与错误响应
- 高性能反射工具：支持类自动实例化、公有属性批量赋值、类元数据缓存，解决传统反射性能损耗问题
适用于所有需要 二进制处理、对象反射、底层数据格式化 的业务场景。
特色核心模块 —— Aurora\Flash
Aurora\Flash 是本库最核心、最具特色的专属模块，是PHP 生态稀缺的完整 AMF 协议实现。
完全对标 Adobe Flex / Flash 官方通信规范，原生实现 AMF0 / AMF3 二进制协议，为 PHP 服务端与 Flex 客户端跨端二进制通信提供一站式、开箱即用的完整解决方案。
Aurora\Flash 核心能力
1. 完整标准协议实现
100% 兼容官方 AMF0、AMF3 协议规范，原生解析、组装、还原 AMF 二进制消息帧；严格遵循 application/x-amf 标准请求响应协议头，完全适配 Flex 远程调用通信机制。
2. 全类型对象完美兼容
支持 AMF 通信中所有主流对象类型：普通实体对象、动态匿名对象（Dynamic Object）、以及 Flex 专属的 IExternalizable 外部化自定义对象。支持开发者自定义二进制读写逻辑，高度灵活适配私有协议业务。
3. 高性能对象反射处理机制
内置全局类元数据缓存系统，避免重复反射开销；通过智能反射机制实现类自动实例化 + 公有属性批量自动赋值，极大提升 AMF 大批量对象解析性能。
4. 统一网关一站式入口
提供 Aurora\Flash\Remoting\Gateway 统一服务入口，极简调用方式，一行代码完成 AMF 请求接收、二进制解析、路由反射、业务调用、协议响应全流程，大幅降低接入成本与学习成本。
适用场景
- 传统 Flex / Flash 老旧项目后端重构、接口迁移、服务升级
- 需要使用 AMF 二进制协议 实现跨端、跨语言通信的业务系统
- 需要底层 二进制流读写、高性能反射、协议编解码 能力的 PHP8 项目
- 需要高性能、低耦合、标准化底层组件支撑的现代化 PHP 业务架构
